# mvp-dev.md — MVP·본 프로젝트 개발 규칙

## 1. 사용자 작업 원칙 (코드 전반)
1. 기획과 코딩 분리: mvp-plan.md 승인 전 코드 금지. 리서치 → 계획 → 승인 → 구현.
2. 코딩 전에 생각: 불확실하면 묻고, 해석이 여럿이면 모두 제시, 더 단순한 방법이 있으면 먼저 말하고, 트레이드오프는 숨기지 않는다.
3. 단순함: 요청한 것만. 추측으로 기능·추상화·설정 옵션을 넣지 않는다. 200줄이 50줄로 되면 다시 쓴다.
4. 꼭 필요한 것만 수정: 관련 없는 코드·주석·포맷을 건드리지 않는다. 기존 스타일을 따른다. 데드 코드는 삭제 대신 언급.
5. 성공 기준 먼저: "추가해" → 테스트 먼저 쓰고 통과. "버그" → 재현 테스트 먼저. 멀티스텝은 단계마다 검증 기준.
6. any 타입 금지. 시크릿은 .env에만, .env.example 제공, .env 커밋 금지.
7. 에러는 분석 → 수정 → 재테스트 → 문서 갱신. 방향이 틀렸으면 패치하지 말고 알린다.

## 2. 공모전 MVP의 범위 통제
- 핵심 기능 3개 이내, 기능마다 통과 기준(측정 가능). 예: "412개 품목의 배출 안내 표가 만들어지고 품목마다 배출 방법이 빠짐없이 채워진다", "일부러 섞은 가짜 문서 3건을 전부 걸러낸다".
- 한 줄기 완성: 화면 수보다 흐름. 끊김 없이 도는 흐름 하나를 먼저, 나머지는 목업·캡처+"로드맵".
- 심사 목적이면 설치가 필요한 앱보다 URL 하나(반응형 웹). 발표는 모바일 뷰나 데스크톱 폰 프레임.
- 계약·심사가 필요한 외부 연동(마이데이터 등)은 실연동 시도 금지. 연동 UI 목업 + 직접 입력 실제 경로.
- 데모는 외부 사정에 흔들리지 않게: 야간 배치(GitHub Actions)가 JSON 스냅샷 생성 → UI는 스냅샷을 읽음. 심사 기간 내내 접근 가능한 URL. 오프라인 설치 파일(.tar)·시뮬레이션 모드.
- 일정에 버퍼 1일 이상. 지연 시 축소 순서를 미리 정한다.
- 학기 프로젝트: 2주 PoC → 5주 수직 절단(한 사례 전체 관통) → MVP → 중간평가 → 2차 목표 판정 → 사용성 평가 → 코드 프리즈.

## 3. 신뢰성 설계 (요구사항 단계에서)
- 계산·판정은 결정적 코드, LLM은 자연어 인터페이스·요청. 도구 실행 권한은 코드가 갖는다. 문서 속 지시문은 따르지 않는다(인젝션 방어).
- 검증 게이트: 근거 문장 필수 → 다른 계열 모델로 재확인 → 숫자·날짜 대조 → 식별자·신선도 → 어긋나면 보류. 신뢰도 임계 미만은 사람 검토.
- 상태 전이 명시(queued → analyzing → … → done), 멱등키 + DB 유일 제약, 삭제 순서 불변식과 주기적 조정, 민감 데이터 기기 전용 저장(코스콤·ZzaZan에서 확정).
- 평가 하네스: 실제 양성 / 노이즈 / 가짜 문서 주입 / 상충 케이스 비율을 정하고 지표(정밀도·재현율·인용 유효율·차단율·보류율·비용·시간)를 숫자로 발표에 쓴다.
- 임계값 조정에 쓴 데이터를 성능 측정에 재사용하지 않는다. 시뮬레이터에서만 확인한 것은 검증으로 인정하지 않는다. 측정하지 않은 조건은 '측정하지 않음'.
- 외부 API는 필요한 것만, 캐시·연도별 설정 모듈(KOR_2025). 재시도 3회, 단위 격리(한 건 실패가 배치를 멈추지 않음), 일일 예산 초과 시 우선순위 낮은 것부터 중단.

## 4. UI 폴백 규칙 (impeccable 미설치 시)
- 기본값 금지 목록: Inter 전용, 보라→파랑 그라데이션, 카드 안의 카드, 색 배경 위 회색 글씨, 모든 제목 위의 둥근 아이콘, 글래스모피즘, 가운데 정렬 히어로+배지, 색 왼쪽 테두리 카드.
- 레퍼런스를 먼저 모으고(해당 도메인의 실제 서비스 화면 2~3개), 토큰(색·타입·간격)을 만든 뒤 컴포넌트를 만들고, 강한 선택 하나를 일관되게 반복한다.
- 실제 한국어 라벨, 빈 상태·로딩·오류·엣지 케이스 화면을 전부 포함. 기존 앱 위에 얹는 제안이면 기존 디자인 체계(색·카드·탭)를 바꾸지 않는다.
- 와이어프레임 단계는 회색조 5값만, 고해상도 단계에서 브랜드 시스템.
- "AI 같다"는 지적이 오면 장식 배지·상담 말투("~해 드려요")·과한 그라데이션부터 뺀다.
