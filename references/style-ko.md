# style-ko.md — 한국어 문체 기준

출처: 실제 기획서 B-7 문체 기준(2026-11-05), im-not-ai(Humanize KR v2.3.2) 요약, 실제 퇴고 기록. 사용자 자산 `~/Downloads/보고서_말투_가이드.md`와 korean-report-tone 스킬이 있으면 그것이 우선한다(`/contest:init`이 플러그인 데이터 폴더의 style/user-report-tone.md로 복사).

## 1. 장르별 기본
| 장르 | 문체 |
|---|---|
| 지원서·기획서 본문 | 합쇼체('~입니다') + 1인칭('제가', '저희는'), 평소 쓰는 말. 문장형 소제목(□). 줄표·굵게·이모지 없음. 짧은 문장 |
| 보충자료·표 | '~다'체와 개조식 |
| 양식이 개조식인 공모전(소마 등) | 이다체·개조식 유지. 가운뎃점 나열, →, ①②③ |
| 매뉴얼 | '~합니다/~하세요', Step 번호, 코드 블록, 좋은 예/나쁜 예 |
| 슬라이드 헤드라인 | 숫자 대비·명사구와 서술형을 섞는다. 전부 '~합니다'로 끝내지 않는다 |
| 발표자 노트 | 반말 구어체 대본 |

## 2. B-7 규칙 (실제 기획서 퇴고 기록 요지)
- 두괄식: 각 항목 첫 줄에 결론, 근거는 뒤. 소제목만 읽어도 흐름이 보이게.
- 번역투 금지: '~에 대한', '~을 통해', '~적인', '~하기 위한', 불필요한 피동('~되어진다').
- 용어: 감독기관·업계가 쓰는 말 그대로. 주최사 호칭을 따른다('손님').
- 숫자: 조사 대상·수치·출처를 한 묶음으로. 24시간제, 날짜는 요일까지. 기대효과 과장 금지.
- 항목 수: 비슷한 항목 6~7개 대신 3~5개. 근거 하나를 쪼개 개수를 늘리지 않는다.
- AI 티 점검: '드물지 않다', '~의 영역이다', '~를 다룬다', '~할 자리다', '순서를 밟는다', 'X가 아니라 Y' 대구 반복, 경구형 마무리, 억지로 맞춘 세 항목, '라벨: 내용' 목록 반복, 줄표. 출처 괄호는 문장마다 달지 않고 참고자료에 모은다.

## 3. im-not-ai 연동
- 설치: `/plugin marketplace add epoko77-ai/im-not-ai` → `/plugin install humanize-korean@im-not-ai`. 명령: `/humanize-scan`(필요 여부), `/humanize [파일]`(전체), `/humanize-redo`(부분), `/humanize-korean`.
- 원칙 그대로: 의미 불변(사실·주장·수치·고유명사·직접 인용), 탐지된 곳만 수정, 장르 유지(리포트를 에세이로 바꾸지 않음), 변경률 30% 경고·50% 중단.
- 심각도: S1 결정적 → 먼저 제거 / S2 한두 번은 두고 3회 이상이면 수정 / S3 겹칠 때만. 패턴 하나로 AI 판정하지 않는다.
- 대분류 A 번역투 · B 영어 과다 · C 구조(이모지, 대구 3회+, 첫째·둘째, 불릿 3연속, 뻔한 헤딩) · D 관용구(결론적으로, 시사하는 바, 크게 세 가지, hype, X에서 Y로) · E 리듬(문장 길이·종결어미 균일) · F 수식 중복 · G 완곡 겹침 · H 접속사 남발 · I 형식명사 과다 · J 시각 장식.
- 손대지 않는 것: 수치·단위·날짜, 고유명사·제품명·모델명, 직접 인용, 법령·규정 조문, 학술·개발 표준 용어(API, prompt, token).
- 고칠 때 새 상투구('결국', '이유다', '더 이상 A가 아니라 B')를 넣지 않는다. 가능형을 단정으로 일괄 변환하지 않는다(정책·의학). 명사형 결말을 '~해야 한다'로 일괄 변환하지 않는다.
- 2차 검사: `python3 -I ${CLAUDE_PLUGIN_ROOT}/scripts/check_style.py <파일> --genre body` S1 0건. 이 파일의 경로는 치환되지 않으므로 style-editor 절차 2의 명령이나 `/contest:verify` 2단계 그대로 실행한다.

## 4. 퇴고 예시 (작업용 → 최종)
> 이 절과 다음 절의 예시 문장은 가상의 분리배출 앱으로 바꿔 적었다. 고친 종류와 문장 틀은 실제 기록 그대로다.

| 고치기 전 | 고친 뒤 | 무엇을 |
|---|---|---|
| 분리배출 규칙을 외워야 하는 숙제에서 버릴 때 찾아보는 안내로 바꾸려는 앱입니다. | 분리배출 규칙은 외우기 어렵습니다. 이 앱은 버릴 때마다 그 자리에서 찾아보게 하려고 합니다. | 'X에서 Y로' 공식을 두 문장으로 |
| 저희가 확인한 것은 주민들이 배출 요일을 자주 헷갈린다는 점입니다. | 저희가 확인해 보니 주민들은 배출 요일을 자주 헷갈렸습니다. | 형식명사 구조를 주어+동사로 |
| 주민에게 필요한 건 긴 안내문이 아니라 짧은 답입니다. | 주민에게는 짧은 답이 필요합니다. | 대구 제거 |
| …배출 민원이 줄어듭니다. | …배출 민원을 줄여 보려고 합니다. | 확정된 미래를 팀의 계획으로 |
| 배출 가이드, 요일 리마인더 | 배출 안내, 요일 알림 | 영어 차용어 풀기 |
| 안내 품목은 주민이 다 외울 수 있는 양이 아닙니다. | 안내 품목은 주민이 다 외울 양이 아닙니다. | 가능형 줄이기 |
| 주민 누구나 분리배출을 정확히 하게 되는 것이 가장 큰 효과입니다. | 효과를 부풀리고 싶지는 않습니다. 확실한 건 주민이 버리기 전에 한 번 확인할 곳이 생긴다는 정도입니다. | 과장 줄이기, 필자 태도 |
| 지금 인력으로는 배출 민원에 매일 답하기 어렵습니다 | 들어오는 배출 민원은 한 달 318건, 담당 주무관은 4명 안팎 | 서술형 헤드라인을 숫자 대비로 |
| 이런 일은 드물지 않습니다. | 기사를 찾아보니 이런 일이 생각보다 자주 있었습니다. | 사람이 안 쓰는 상투구 |

## 6. 교정 루프 (실제로 효과가 있었던 순서)
1. 사용자가 AI 같은 문장 하나를 지목하면 그 패턴을 문서 전체에서 찾는다.
2. 외부 기준을 다시 본다(보고서 작법, AI-티 가이드, 같은 장르의 실제 문서).
3. 재작성 후 check_style 0건, humanize 변경률 30% 이하.
4. 고치기 전·후를 나란히 남겨 사용자가 되돌릴 수 있게 한다.
5. 이미지·슬라이드에도 적용: 장식 배지, 상담 말투, 사족 캡션 제거.
