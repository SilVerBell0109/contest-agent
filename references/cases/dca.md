# 사례: 제43회 DCA(대학생 광고대상) 월드콘·처음처럼·에어리즘 (2026.7.28~29, 기획만 확인)

- 유형: 광고·크리에이티브(--type ad). 소프트웨어 공모전이 아니지만 사용자의 아이디어 판단 기준이 가장 선명하게 드러난 기록이라 남긴다.
- 입력: 과제 브리프 사진 + 전년도(42회) 수상작 사진 + 카테고리 목록. 요청: "42회 수상작을 참고해 수상권 상위 1%의 아이디어".

## 작업 순서
1. **수상작 문법 분석**이 먼저. 42회 두 편에서 뽑은 문법: 새로 만들지 않고 이미 있는 접점에 얹기 / 시원함 대신 민망함·찝찝함 같은 감정 / 기능의 물리적 은유 / 즉시 구매 연결 / 작품명이 곧 아이디어 요약 / 숫자 전환 공식(그랑프리 '탄산 22% → 찬바람 22초' → 에어리즘 '코튼 한 번 마를 때 두 번', 월드콘 '1986년 → 19.86초').
2. **브리프 오독 방지**: 처음처럼 브리프의 '새로'를 경쟁사로 읽으면 자사 브랜드 공격이 됨. 도수 변화(19.8 → 16)는 "헤리티지를 숫자로 갖고 있으니 그 문법을 쓰라"는 신호로 해석.
3. **장소 판정 기준표**(사용자 기준을 표로): 결핍의 즉시성 / 장소의 필연성 / 체류 시간 / 혼잡·민원 / 타깃 밀집. 월드콘에서 쓴 기준이 에어리즘 에스컬레이터 안에 그대로 재사용.
4. 사용자가 Claude 안을 연속 기각하고 자기 안(DOOH 전광판 4개 × 프리미엄 3종)을 냄 → Claude는 구조만 손봄(QR을 판매 링크가 아니라 개인화 영상 수령 장치로, 19.86초 자산화).
5. 어법·카피 검증: '첫 승진처럼'이 안 붙는 이유('처럼'은 때를 가리키는 말에 붙음)를 설명하고 배치로 해결('첫 승진 / 처음처럼'). 20주년 리뉴얼 해에 로고 해체는 "헤리티지 훼손" 위험 → 로고는 두고 라벨 주인공 자리만.
6. 방어 지점 명시: "창피 주는 광고로 읽히면 실패", 촬영 스크린의 프라이버시 설계 한 줄 → 실행 가능성 가점.
- 산출물: 브리프보드 문안(인사이트·아이디어·백그라운드·기대효과·방안), Figma용 SVG 화면.

## 기각된 후보와 이유(사용자 원문 기준)
| 후보 | 이유 |
|---|---|
| 신호등 그늘막, 트로피 포디움, 산 정상 | 브랜드 특정성 없음, 맥락 개연성 없음 |
| 지하철 계단 | 이동 중인 사람 — 그 심리 상태가 아님. 머무는 곳(페스티벌·한강)이어야 |
