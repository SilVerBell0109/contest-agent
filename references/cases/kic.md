## 주제 경로 — 관문 비교의 원형
- A(Holdings Sentinel) vs B(GP Watch, 위탁운용사 감시)를 양쪽 상세히 쓴 뒤 처음엔 "A 본체, B 확장" 절충 → 사용자 "무조건 수상하고 싶은데 둘 중 하나 추천한다면?" → A 단독 추천. 이유는 "아이디어가 더 좋아서가 아니라 수상 관문에서 실패 확률이 낮아서".
- 관문별 판단: 상호평가(한 장으로 이해) / 전문가 실현가능성 20점(데이터 전부 실제·공개) / 본선 구현 완성도 25점·동점 1순위(개인 19일 파이프라인형) / 신뢰성 15점(원문 인용·이중 검증 시연) / Q&A(막을 반박 하나) / 본인 역량(백엔드).
- B의 핵심 가치는 확장 1순위로 흡수. 폐기 이유: 합성 데이터 의심, 도메인 학습 부담, 19일 개인 구현 위험.
- 그 뒤 사용자 지시는 "그러면 A로 해서 더 자세히 조사해줘" 한 줄.
