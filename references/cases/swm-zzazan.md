# 사례: SW마에스트로 17기 'ZzaZan' 기획서·중간보고서 (2026.6~9)

- 유형: 프로그램(기획심의·중간점검). 연수생 3명 + 멘토 3명. 온디바이스 AI로 '내 아이' 사진을 고르고 태그·검색·가족 공유하는 육아 사진 앱.
- 양식: 요약 1쪽 + 기획서 10쪽. 대항목(□)·소항목(ㅇ) 추가·삭제·순서 변경 금지, 글자 크기 고정, 기본 표 삭제 금지, 파란 안내문 삭제, 목차 갱신. 심사 대신 ✅ 질문 6개(무엇을/기존과 차이/첨단 기술/시간·자원/접근 효과성/수요자와 성공 후 변화).

## 주제 경로
- 소마 멘토 7명 설문으로 후보 가치 맞비교: 정리 어려운 이유 '양이 많아서' 6, 정리 앱 사용 0, 태그 검색 긍정 7, 포토북 자동 완성은 갈림 → "매력적이지만 후순위인 산출물 제작은 분리". 표본 한계(설문 대상이 실제 사용자층과 다름)를 2판부터 명시.
- 1판 '못 찾음+용량 부족' 6기능·요금제 → 2판 온디바이스 정리·검색·공유, 클라우드 시장 수치 삭제 → 팀 최종 "진입 지점은 저장 용량이 아니라 다시 찾기" 3기능 → 중간보고서 '고르기(베스트컷)+공유'. 강자(저장 용량)가 차지한 축을 피하고 빈틈을 한 문장으로.
- 클라우드 저장을 뺀 결정은 R2 저장료 vs 광고 매출 손익 계산 끝에 사용자가 선언. Claude는 "제품 정체성이 바뀌는 결정"이라며 함의 표 + 다음 결정 2개를 물었다.
