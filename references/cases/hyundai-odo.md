## 기획 배경의 짜임
□ 문장형 소제목 5개: 점수는 많은데 매일 안 봄(티맵·보험 할인 20%대·1년차 팀원 경험) / 차로 다녀온 곳을 모아 주는 서비스 없음(스트라바·만보기 비유) / 차 안 화면은 어려우면 아무도 안 씀(Vertu 64%, J.D. Power 13,269명) / 폰 앱으로는 안 풀림(차량 신호·가족 공유차·주행 중 조작) / 차 안에서 바라는 것(904명 설문, 즐거움).

## 설계를 표 15개로
주행 상태 3단계(판정 신호·보이는 것·허용 입력) / 안전 XP(1 km 무사고 10 XP, 위험 이벤트 5종, 교통안전공단 기준에서 출발, 보너스, 하루 300 상한, 연속 보너스) / 레벨 6단계 / 업적 6갈래(10분 정차, 집·직장 1 km 내 제외, TourAPI 좌표) / 로드 레이더(100 m 격자, 임시 ID 30초, 80 km/h 이상 3초 갱신) / 안전·프라이버시 기본값 14행(이동 중 터치 전면 잠금, 음성 10분 2회, 카운트다운 업적 없음, 홈존 500 m, 신원 입력란 없음, 위치정보법) / 친구(50명 상한, 전체 순위표 없음 — 직업 운전자 독식·과속 유발) / SDK 5종(받는 데이터·역할·확인할 것) / 일정 3단계 / '확인할 것 → 안 될 때 대안' 5행 / 타깃 3단 / 유지 목표(D1 70%, D30 40%) / 경쟁 비교(스트라바는 "참고이면서 반면교사") / MAU 역산(30만 대 × 25% × 50% ≈ 4만).

## 작업용 → 최종의 변화
- 자리표시 해소: 【팀원 경험 한두 문장】 → 실제 팀원 이야기; 【약관 재확인 필요】 → 삼성화재 TMAP 1.5~26.5% 등 실제 수치; 【원문 확인 필요】 → 인용 논문(김유원·강준규, 2015).
- 근거 추가(Vertu, J.D. Power), 문단 규칙을 표로, 일정 2 → 3단계, 아이콘 v4 → v5.
- 문장 퇴고: 'X에서 Y로' 공식, 'A가 아니라 B' 대구, 영어 차용어(카탈로그·스트릭) 제거. 확정 미래("커뮤니티가 됩니다") → 계획("키우려고 합니다").
