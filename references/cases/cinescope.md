# 사례: 국민대 알파프로젝트 'CINE:SCOPE' (2026.7.15~7.26)

- 유형: 프로그램 신청서(학내, 9학점·15주·270시간). 팀 5 → 4명(사용자 팀장). 영화 감상 중 현재 쇼트의 촬영 문법을 AI가 분석해 옆 패널·오버레이로 보여 주는 웹.
- 선발 기준 4축 각 25점(체계성/자기주도성, 구체성/실용성, 실현가능성/합리성, 공공성/학교 홍보). 감점: 외부 콘텐츠 소개만, 조사만, 2장 이내, 무리한 편성. 가산점: 공모전 출품 예정, 동아리 기반 팀.
- 7/23 오전 10:30~12:15에 보충자료 6판, 역량표 2판. 파일명에 버전+바뀐 점, 문서 머리에 변경 로그.

## 주제 경로
- 여러 라운드 브레인스토밍(이미지 무드 → UI 코드 프롬프트 변환 서비스 등) 후 영화 분석으로. 선정 기준: 팀원(예술대) 강점, CV 역량, **실사용자·실데이터 없이도 성립**.
- 배경은 영진위 통계(극장 관객 13.8% 감소, OTT 56.1% vs 극장 8.3%, 특수상영 매출 46.3% 증가) → "관객이 떠난 게 아니라 보는 방식이 바뀌었다". 핵심 전환 한 줄: '어떤 영화를' → '어떤 장면과 연출을'.
- 경쟁 3유형(감상 기록형/분석 콘텐츠/전문 도구) 포지셔닝 표에서 '감상 중(실시간)'·'수치 공개'를 빈칸으로.

## 고도화
- 범위를 공개 벤치마크로 잘랐다: ShotBench(arXiv:2506.21356) ShotVL-3B 항목별 정확도 → 85.6% 프레이밍부터 MVP, 51.7% 카메라 움직임은 2차 실험 후 판정. "근거 없이 축소한 것이 아니라 공개 지표로 한 학기 달성 수준을 설계 단계에서 판단".
- 차별점 둘로 압축: 쇼트 타임라인 색 띠, AI 한계 공개(신뢰도 표시, 직접 라벨링한 검증 세트 200쇼트, 오류 신고).
- 저작권: 퍼블릭 도메인 고전 + CC BY 단편·오픈무비만. ShotVL은 '구성요소', 파이프라인·검증은 직접 개발.
- 일정 재편: 2주 PoC → 5주 수직 절단(영화 1편 관통) → 6주 MVP → 8주 중간평가 → 11주 통합 판정 → 12주 사용성 평가 → 14주 코드 프리즈.
- 심사표 대응을 문장으로 박음: "외부 공개 모델을 '소개'하거나 '구동만' 하는 활동이 아니다" + 독자 개발 범위 표; 동아리 문단(가산점); 교내 공개·정확도 리포트(공공성).
- 역량표: 처음 5명 스택을 추정해 채웠다가 **본인 행만 실제 이력, 나머지는 '(기입 필요)'로 되돌림** — 남의 이력을 추정하지 않는다.

## 제출본에 남은 결함 (→ 검수 항목이 됨)
- KPI 표 머리에 대화 지시문 "(사용자 원칙: 성공 기준을 먼저 정의하고 실행)" 잔존.
- 마크다운 `**` 잔재("**RAG(…)**를"), 물결표 취소선, 그림 캡션 어긋남.
- 새로 넣은 RAG가 목표·KPI·리스크엔 있는데 주차 계획·개인 계획·담당·기대효과·비용엔 없음(일관성).
- 팀원 이탈 후 담당자 빈 화면, 구현(6주)이 디자인(7주)보다 앞섬.
