# 시연 영상·발표 시연 대본 — 【서비스명】

## A. 시연 영상 (60~90초, 1차 접수용)
| 장면 | 시간 | 화면 | 내레이션(구어체) | 보여 줄 숫자(E-ID) |
|---|---|---|---|---|
| 1 문제 | 0:00~0:15 | | | |
| 2 핵심 흐름 | 0:15~0:45 | | | |
| 3 여기서만 되는 것 | 0:45~1:05 | | | |
| 4 결과·다음 | 1:05~1:30 | | | |

- 실제 데이터로 찍는다. 가상 데이터를 쓰면 화면에 '예시'를 표시한다.
- 실패 대비: 녹화본 + 스냅샷 모드. 외부 API가 죽어도 돌아가는 경로를 먼저 확인.

## B. 발표 시연 (10분 발표 중 3~4분)
1. 한 문장으로 오늘 보여 줄 것
2. 장면 1 → 2 → 3 (각 장면의 '멈추고 설명할 지점')
3. 숫자 세 개로 마무리(평가 하네스 결과)
4. 백업: 실패 시 전환할 녹화 구간
